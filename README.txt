## How to publish
1. Purchase/register `advocatajay.com` through a domain registrar.
2. Purchase web hosting that supports static HTML.
3. Upload `index.html` and the `assets` folder to the hosting public/root folder.
4. Point the domain DNS to the hosting provider.
5. Enable HTTPS/SSL in the hosting dashboard.
